一、軟體簡介與特色
--------------------------------------------------------------------------------
SAIGENT快捷翻譯 是一款專為 Windows 桌面打造的雙模 AI 翻譯神器。
完美整合「螢幕截圖原位對位覆蓋」與「反白劃詞即時浮動翻譯」，
支援微軟 Windows 內建 OCR 與 PP-OCRv5 離線辨識，結合企業級 LLM 大語言模型，
帶給您如同軟體原生中/英文版的極致流暢體驗。

★ 核心特色：
1. 雙模即時翻譯：支援螢幕截圖覆蓋與反白文字劃詞（Ctrl + C + C）兩種模式。
2. 原位覆蓋 (In-Place Overlay)：截圖翻譯直接在螢幕原本文字上方覆蓋譯文，排版精準不位移。
3. Windows 原生 OCR (預設推薦)：調用系統原生引擎，中英皆通，100% 離線免外網。
4. PP-OCRv5 離線辨識：內建模型備援，精準度高，複雜排版辨識力強。
5. 自動採樣背景色：智慧分析背景色並自動排除文字雜訊，色彩融合自然不突兀。
6. 懸浮透視：滑鼠移至任一譯文方塊，自動半透明化（透明度 85%），隨時核對原文。
7. 智慧語系偵測：劃詞翻譯自動分析中英比例，免手動切換方向即可自動雙向翻譯。
8. 本地 LLM 防爆保護：劃詞翻譯提供動態字數限制，保護模型免於記憶體溢出或延遲。

二、雙模翻譯核心功能與操作
--------------------------------------------------------------------------------
【模式 A：螢幕截圖原位覆蓋翻譯】
適用場景：無法反白複製文字的軟體選單、遊戲畫面、圖片、圖表或不可選取之網頁。

1. 觸發截圖：
   在任何介面隨時按下全域快速鍵【Ctrl + Shift + T】（或點擊主視窗「開始截圖」）。
2. 框選區域：
   按住滑鼠左鍵拖曳拉出矩形框後放開。
   ※ 秘訣：在選取畫面中直接按下【空白鍵 (Space)】，可一鍵自動全螢幕翻譯！
3. 開始翻譯：
   點擊浮動工具列上的「開始翻譯」，系統自動完成：
   [局部截圖] -> [文字識別] -> [AI 翻譯] -> [原位渲染覆蓋]。
4. 結束離開：
   按下鍵盤【Esc】或點擊畫面空白處，即可隨時關閉覆蓋層返回桌面。

【模式 B：反白劃詞即時選取翻譯（免 OCR）】
適用場景：網頁文章、PDF、程式碼註解、Word 等可直接選取文字的環境。

1. 選取文字：
   使用滑鼠反白選取任意想要翻譯的段落或句子。
2. 觸發翻譯：
   按著鍵盤【Ctrl】鍵不放，並連按兩次【C】鍵（即 Ctrl + C + C）。
3. 浮動視窗：
   滑鼠游標旁會立即彈出輕量化的 AI 翻譯視窗，自動顯示原文與譯文。
4. 結束離開：
   按下鍵盤【Esc】或點擊視窗外任意處即可快速關閉。

三、特色功能與快捷操作
--------------------------------------------------------------------------------
1. 【滑鼠懸浮透視 (Peek Original)】
   截圖譯文覆蓋在畫面上時，若想看原本文字，只需將游標移到該文字上方，
   方塊會立刻變成淡透明狀態，移開後瞬間恢復覆蓋。

2. 【點擊複製單行與一鍵複製全部】
   - 截圖覆蓋模式：點擊任一譯文方塊即可複製該行內容；點擊底部「複製全部譯文」可匯出所有行。
   - 劃詞翻譯模式：點擊右下角「📋 複製譯文」按鈕，秒速複製翻譯結果。

3. 【自適應排版與防破版】
   系統針對短詞、按鈕與長段落具備多重排版防護，短英文翻成長中文時自動平滑展開，
   密集列表自動限制最大寬度，確保文字不截斷、不重疊、不撕裂。

4. 【劃詞視窗釘選與手動切換語系】
   - 釘選置頂：點擊右上角「📌 釘選」圖示，視窗將固定於最上層，點擊外部不會自動消失。
   - 快速切換：點擊「⇄ EN / 中」，可手動強制切換翻譯方向並重新請求 AI 翻譯。

--------------------------------------------------------------------------------
四、軟體設定 (⚙)
--------------------------------------------------------------------------------
點擊主視窗右上角的「設定 (⚙)」圖示，可自訂以下偏好設定：

1. 翻譯方向 (Translation Direction)：
   - 中→英 (zh -> en)：將繁體中文介面翻成自然流暢的英文。
   - 英→中 (en -> zh)：將外文軟體、文件翻成繁體中文（臺灣用語風格）。

2. OCR 辨識引擎 (OCR Engine)：
   - Windows OCR (預設推薦)：調用 Windows 內建 OCR 引擎，原生支援中英數混排，繁中系統相容性最佳、免額外套件。
   - PP-OCRv5 (離線模型)：精準度極高，支援複雜圖形排版與特殊符號。

3. 自訂截圖快速鍵 (Custom Shortcut)：
   點擊快速鍵輸入框旁的「錄製」按鈕，直接在鍵盤上按下您習慣的組合鍵
   （如 Alt + T、Ctrl + Alt + A 等）即可完成設定並自動註冊全域熱鍵。

4. 劃詞即時選取翻譯開關 (Ctrl + C + C Toggle)：
   可自由開啟或關閉「按著 Ctrl 連按兩次 C」喚起劃詞翻譯功能。

5. 劃詞翻譯字數上限保護 (Max Selection Characters)：
   - 設定單次劃詞翻譯的字元上限（安全範圍：100 ~ 2,000 字元，預設 800 字）。
   - 當選取內容超過上限時，系統會自動擷取前段文字進行翻譯，保護本地端 LLM 模型避免記憶體爆滿或卡頓。

--------------------------------------------------------------------------------
五、常見問題與疑難排解 (FAQ)
--------------------------------------------------------------------------------
Q：劃詞翻譯（Ctrl + C + C）沒有反應怎麼辦？
A：請確認操作手勢為「按著鍵盤左下角 Ctrl 鍵不要放開，接著快速點擊兩次 C 鍵」。若依然無反應，請至「設定 ⚙」確認該選項已被勾選啟用。
