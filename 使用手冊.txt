一、軟體簡介與特色
--------------------------------------------------------------------------------
SAIGENT快捷翻譯 是一款專為 Windows 桌面設計的原位（In-Place）截圖與劃詞翻譯工具。
透過高精準度離線 OCR 識別與 LLM 翻譯引擎，將螢幕上的文字直接在「原位置」
以完美貼合的背景底色覆蓋上翻譯後的結果，帶給您如同軟體原生中/英文版的流暢體驗。

★ 核心特色：
1. 原位覆蓋 (In-Place Overlay)：直接覆蓋在螢幕原本文字上方，排版不位移。
2. PP-OCRv5 離線辨識：預設內建最新離線 OCR 引擎，無需聯網即可秒速識別文字。
3. 自動採樣背景色：智慧分析背景色並自動排除文字雜訊，融為一體不突兀。
4. 懸浮透視：滑鼠移至任一譯文方塊，自動半透明化（透明度 85%），隨時核對原文。
5. 靈活複製：點擊任一譯文單行即可複製；亦支援一鍵複製全部翻譯。
6. 自適應排版：支援短中文翻譯成長英文時自動延伸展開，文字絕不截斷。

二、快速入門（操作五步驟）
--------------------------------------------------------------------------------
【步驟 1：啟動軟體】
  直接執行「screen-translator.exe」即可啟動。啟動時會自動載入離線辨識引擎。

【步驟 2：觸發截圖】
  在任何軟體或網頁中，隨時按下全域快速鍵（預設為：Ctrl + Shift + T），
  或點擊主視窗上的「開始截圖」按鈕，畫面將暫停並進入選取模式。

【步驟 3：框選範圍】
  按住滑鼠左鍵拖曳，拉出想要翻譯的區域矩形框後放開。
  ※ 小秘訣：在選取畫面中直接按下【空白鍵 (Space)】，可直接自動選取全螢幕進行翻譯！

【步驟 4：執行翻譯】
  框選完成後，工具列會顯示「開始翻譯」按鈕，點擊後系統將自動完成：
  [局部截圖] -> [文字識別] -> [翻譯] -> [原位渲染覆蓋]。

【步驟 5：檢視與結束】
  - 檢視：直接在螢幕上瀏覽覆蓋後的譯文。
  - 離開：按下鍵盤【Esc】或點擊畫面空白處，即可隨時關閉覆蓋層返回桌面。

--------------------------------------------------------------------------------
三、特色功能與快捷操作
--------------------------------------------------------------------------------
1. 【滑鼠懸浮透視 (Peek Original)】
   當譯文覆蓋在畫面上時，若想看原本的文字，只需將滑鼠游標移到該文字上方，
   該方塊會立刻變成淡透明狀態，移開後瞬間恢復覆蓋。

2. 【點擊複製單行】
   點擊任一個翻譯方塊，該行的譯文內容會立即複製到系統剪貼簿。

3. 【一鍵複製全部】
   點擊底部工具列的「複製全部譯文」，所有辨識並翻譯出的內容將依行號整理複製。

4. 【快速鍵隨按隨翻】
   隨時使用快速鍵（預設 Ctrl + Shift + T）召喚截圖；在覆蓋模式下再按一次快速鍵
   或按 Esc 即可秒速關閉。

--------------------------------------------------------------------------------
四、軟體設定
--------------------------------------------------------------------------------
點擊主視窗右上角的「設定 (⚙)」圖示，可進行以下配置：

1. 翻譯方向 (Translation Direction)：
   - 繁中 -> 英文 (zh -> en)：將畫面上的中文選單、軟體或按鈕翻成英文。
   - 英文 -> 繁中 (en -> zh)：將外文介面、文件或英文選單翻成繁體中文。

2. OCR 辨識引擎 (OCR Engine)：
   - Windows 內建 OCR (預設推薦)：調用 Windows 系統內建 OCR API（中英皆可，免額外依賴）。
   - PP-OCRv5 (離線模型)：精準度最高、支援符號與複雜排版，不需聯網。
